Mini Task Manager

A simple task management system built using ASP.NET Core Web API and SQL Server.

Project Overview

Mini Task Manager is a web application designed to help users organize and manage their daily tasks.

Technologies Used

* C#
* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* Swagger

Current Features

* Create tasks
* View all tasks
* Update existing tasks
* Delete tasks
* Mark tasks as completed or incomplete
* Store tasks in SQL Server database

Project Structure

* Controllers: Handles API requests.
* Data: Contains the database context.
* Models: Contains task data models.
* Migrations: Contains database migrations.

Project Status

Backend development is in progress. The Angular frontend will be added in a later stage.
